## 公共特性说明

在介绍具体插件前，先说明所有插件共享的能力与约定，避免在每个插件中重复。

### 1. 继承基类 BasePlugin

所有插件继承 [BasePlugin](../src/plugins/base_plugin/base_plugin.py)，必须实现：

```python
def generate_image(self, settings, device_config) -> PIL.Image
```

可选覆盖：
- `generate_settings_template()` — 返回模板变量，可声明 `api_key` / `style_settings` / `hide_refresh_interval` 等
- `cleanup(settings)` — 资源清理
- `get_loop_weight(settings)` — 随机轮播权重

### 2. AdaptiveImageLoader（`self.image_loader`）

BasePlugin 注入的图像加载器，自动适配低内存设备（Pi Zero），主要方法：

| 方法 | 用途 |
|---|---|
| `from_url(url, dimensions, timeout_ms, fit_mode)` | 从 URL 加载并按 `fit_mode`（`fit`/`fill`/`blur`）适配 |
| `from_file(path, dimensions, resize, fit_mode)` | 从本地文件加载 |

**fit_mode 三种模式**：
- `fit` — 等比缩放后留白（letterbox），背景色由插件决定
- `fill` — 等比缩放后裁剪填满
- `blur` — 缩放后用模糊放大的原图做背景填充（`pad_image_blur`）

### 3. API Key 声明

在 `generate_settings_template()` 中通过 `api_key` 字典声明：

```python
template_params['api_key'] = {
    "required": True,                       # 是否必须
    "service": "OpenWeatherMap",            # 服务名（显示用）
    "expected_key": "OPEN_WEATHER_MAP_SECRET"  # .env 中的键名
}
```

运行时通过 `device_config.load_env_key("KEY_NAME")` 读取。Web UI "API Keys" 页统一管理。

### 4. style_settings

设为 `True` 后，设置页自动渲染"样式"区块，让用户选择背景色、文字颜色、边框样式（frame_styles 由 BasePlugin 提供）。

### 5. hide_refresh_interval

设为 `True` 后，设置页隐藏"刷新间隔"字段。用于自身管理刷新逻辑的插件（如 ISS Tracker、Flight Tracker、ShazamPi）。

### 6. 显示无关性约定

- 用 `device_config.get_resolution()` 获取分辨率
- 用 `device_config.get_config("orientation")` 判断方向，vertical 时反转 dimensions
- 字体大小用 `int(min(height * 0.05, width * 0.04))` 等相对公式
- 禁止硬编码像素

### 7. 时区处理

- 从 `device_config.get_config("timezone", default="America/New_York")` 获取时区字符串
- 用 `pytz.timezone(name)` 或 `zoneinfo.ZoneInfo(name)` 转换
- 时间格式由 `device_config.get_config("time_format", default="12h")` 控制（12h / 24h）

### 8. 错误处理约定

- 配置缺失、API key 无效、网络失败等场景：`raise RuntimeError("面向用户的清晰错误信息")`
- 错误信息会在 Web UI 弹窗显示，不会让服务崩溃
- 日志使用 `logging.getLogger(__name__)`

### 9. 字体

通过 `utils.app_utils.get_font(family, size, weight)` 获取。内置字体族：
- **Jost** — 通用无衬线（大部分插件默认）
- **DS-Digital** — 数字风格（Clock 数字面）
- **Inter** / **Roboto** 等

## 1. AI Image

> 源码：[src/plugins/ai_image/ai_image.py](../src/plugins/ai_image/ai_image.py)

### 功能

调用 AI 模型（OpenAI DALL-E 或 Google Gemini）生成图像并显示。支持两种 prompt 来源：

- **手动输入** — 用户在设置页填写文字描述
- **新闻标题** — 从预设 RSS（BBC / Reuters / AP / NPR / NYT / Ars Technica / The Verge）或自定义 URL 抓取随机标题，再用 GPT-4 改写为编辑插画风格 prompt

支持 **prompt 随机化**：用 GPT-4 或 Gemini Flash 把用户原始 prompt 改写为更生动、随机风格的版本（17 种视觉风格：照片、水彩、铅笔、油画、像素艺术等）。

### 依赖

- `openai` Python SDK
- `google-genai` Python SDK（Gemini）
- `feedparser`（新闻标题模式）
- **API Key**：`OPEN_AI_SECRET` 或 `GOOGLE_GEMINI_SECRET`（二选一，按所选 provider）

### 支持的模型

| Provider | 模型 |
|---|---|
| OpenAI | `dall-e-3`、`dall-e-2`、`gpt-image-1`（默认 `dall-e-3`） |
| Gemini Imagen | `imagen-4.0-generate-001`、`imagen-4.0-fast-generate-001`、`imagen-4.0-ultra-generate-001` |
| Gemini Native | `gemini-2.5-flash-image`、`gemini-3-pro-image-preview`、`gemini-3.1-flash-image-preview` |

### 配置项

| 键 | 说明 | 默认值 |
|---|---|---|
| `provider` | `openai` 或 `gemini` | `openai` |
| `promptSource` | `manual` 或 `news` | `manual` |
| `textPrompt` | 手动模式的 prompt | — |
| `randomizePrompt` | 是否随机化 prompt | `false` |
| `imageModel` | OpenAI 模型 | `dall-e-3` |
| `geminiImageModel` | Gemini 模型 | `imagen-4.0-generate-001` |
| `quality` | 图像质量 | `medium` / `standard` |
| `newsFeeds` | 逗号分隔的预设 feed key | `bbc` |
| `customFeedUrl` | 自定义 RSS URL | — |
| `fitMode` | `fit` / `fill` | `fit` |
| `showTitle` | 是否显示标题叠加条 | `true` |

### 开发要点

- 自动按方向选择尺寸：DALL-E 3 用 `1792x1024`（横）或 `1024x1792`（竖），gpt-image-1 用 `1536x1024` / `1024x1536`
- Gemini 调用 `response_modalities=["IMAGE"]`（Native）或 `generate_images()`（Imagen），两条代码路径
- 标题叠加条：底部全宽半透明黑条 + 白色 Jost Bold 文字，自动截断超过 10 词的标题
- API key 会被 `encode('ascii', errors='ignore')` 清洗，避免复制粘贴引入的不可见字符
- 友好错误：429 → 限流提示，401 → 密钥无效，404 → 模型不存在

## 2. AI Text

> 源码：[src/plugins/ai_text/ai_text.py](../src/plugins/ai_text/ai_text.py)

### 功能

向 AI 模型发送 prompt，将返回的文本（≤70 词）渲染到屏幕。支持 OpenAI 与 Gemini 双 provider。对"讲笑话"类请求有特殊处理：随机选择喜剧风格（witty / silly / dry / absurd 等）与话题（科技 / 食物 / 动物等）避免重复。

### 依赖

- `openai`
- `google-genai`
- **API Key**：`OPEN_AI_SECRET` 或 `GOOGLE_GEMINI_SECRET`

### 支持的模型

| Provider | 模型 |
|---|---|
| OpenAI | `gpt-4o-mini`、`gpt-4o`、`gpt-4.1`、`gpt-4.1-mini`、`gpt-4.1-nano`、`gpt-5`、`gpt-5-mini`、`gpt-5-nano` |
| Gemini | `gemini-2.0-flash`、`gemini-2.0-flash-lite`、`gemini-1.5-flash` |

### 配置项

| 键 | 说明 |
|---|---|
| `provider` | `openai` 或 `gemini` |
| `textPrompt` | 用户请求（必填） |
| `title` | 显示标题（留空则从 prompt 截取前 40 字符） |
| `textModel` | OpenAI 模型 |
| `geminiTextModel` | Gemini 模型 |
| `backgroundColor` / `textColor` | 样式（启用 `style_settings`） |

### 开发要点

- Gemini 调用使用 `temperature=2.0` + 随机 `seed` 防止缓存重复
- 文本居中渲染，标题带下划线，正文用引号包裹
- 支持字面 `\n` 转换为真实换行（用于诗歌、列表等格式）
- 字体大小自适应屏幕：`title_size = int(min(height * 0.08, width * 0.07))`

## 3. APOD

> 源码：[src/plugins/apod/apod.py](../src/plugins/apod/apod.py)

### 功能

获取 NASA **天文每日一图**（Astronomy Picture of the Day）。支持三种日期模式：
- 今日（默认）
- 自定义日期
- 随机日期（2015-01-01 至今）

遇到视频（非图像）会自动重试，最多 10 次。优先使用标准分辨率 URL（避免 4000px+ HD 图导致 Pi Zero OOM）。

### 依赖

- `requests`（通过 `get_http_session()`）
- **API Key**：`NASA_SECRET`（[获取地址](https://api.nasa.gov/)，免费）

### 配置项

| 键 | 说明 |
|---|---|
| `randomizeApod` | 是否随机日期 |
| `customDate` | 自定义日期（`YYYY-MM-DD`） |
| `fitMode` | `fit` / `fill` |
| `showTitle`（代码内） | 标题叠加 |

### 开发要点

- API：`GET https://api.nasa.gov/planetary/apod?api_key=...&date=...`
- 标题叠加：底部黑条 + 白字 + 黑色描边（`stroke_width=2`），用 `re.sub` 清理 HTML 实体
- 重试逻辑：自定义日期/今日模式下逐日回退，随机模式重新随机

## 4. Art Museum

> 源码：[src/plugins/art_museum/art_museum.py](../src/plugins/art_museum/art_museum.py)

### 功能

从 **大都会艺术博物馆**（Met）或 **芝加哥艺术博物馆**（Art Institute of Chicago）随机展示艺术作品。无需 API Key。

支持按类型筛选：
- Paintings（绘画）
- Photos（摄影）
- Others（其他）

可选来源：`met` / `chicago` / `both`（随机二选一）。

### 依赖

- 仅 `requests`，无 API Key

### 配置项

| 键 | 说明 | 默认 |
|---|---|---|
| `museum` | `met` / `chicago` / `both` | `both` |
| `artPaintings` | 启用绘画 | `true` |
| `artPhotos` | 启用摄影 | `true` |
| `artOthers` | 启用其他 | `true` |
| `showTitle` | 显示标题+作者+年代叠加 | `true` |
| `fitMode` | `fit` / `fill` | `fit` |

### 开发要点

- **Met 缓存**：`_met_ids` 在实例生命周期内缓存所有 objectID 列表（约 490k 条），避免每次刷新都拉全量
- **Chicago 分页**：随机页码 1-5000，每页 1 条
- **分类逻辑**：Met 用 `classification` 字段，Chicago 用 `artwork_type_title`
- 优先使用 Met 的 `primaryImageSmall`（web 尺寸）而非 `primaryImage`（4000px+）
- Chicago 用 IIIF URL：`https://www.artic.edu/iiif/2/{image_id}/full/1024,/0/default.jpg`
- 标题叠加含主标题（白色）+ 副标题（艺术家, 年代，灰色），均带描边
- 用二分搜索截断过长标题（`_truncate_to_width`）

## 5. Astro Targets

> 源码：[src/plugins/astro_targets/astro_targets.py](../src/plugins/astro_targets/astro_targets.py)

### 功能

为 backyard astrophotographer（后院天文摄影爱好者）计算 **今晚最佳深空摄影目标**。

基于 [Skyfield](https://rhodesmill.org/skyfield/) 天文库：
- 计算天文暮光 dusk → dawn 观测窗口
- 用本地地平线 profile（JSON，方位角→最小高度）过滤目标
- 向量化计算所有目标在窗口内的可见时段与峰值高度
- 按综合评分（高度 40% + 可见时长 40% + 亮度 20%）排序
- 计算月相与月亮位置（避免月光干扰）
- 为每个目标推荐最佳器材（FOV 匹配，目标应填充 30-80% 短边）

### 依赖

- `skyfield`（天文计算）
- `numpy`
- `pytz`
- **资源**：`resources/targets.json`（精选 DSO 目录）、`resources/de421.bsp`（JPL 星历，首次自动下载）

### 内置器材 Profile

| 名称 | FOV (宽×高, 度) |
|---|---|
| ZS61 + ASI2600MM | 3.74 × 2.50 |
| SeeStar S50 | 2.0 × 1.3 |
| FF107 + ASI2600MM | 1.93 × 1.29 |
| ZS61 + ASI174MM | 1.80 × 1.13 |
| FF107 + ASI174MM | 0.93 × 0.58 |

### DSO 类型

emission_nebula、reflection_nebula、planetary_nebula、dark_nebula、supernova_remnant、galaxy、galaxy_group、open_cluster、globular_cluster（各有专属图标颜色）

### 配置项

| 键 | 说明 | 默认 |
|---|---|---|
| `latitude` / `longitude` | 观测点坐标 | `32.7767, -96.7970`（达拉斯） |
| `maxTargets` | 显示前 N 个目标 | `4` |
| `horizonProfile` | 地平线 JSON | 内置默认 |
| `type_<type>` | 启用各 DSO 类型 | 全 `true` |
| `equip_<name>` | 启用各器材 | 全 `true` |
| `backgroundColor` / `textColor` | 暗色主题 | `#1a1a2e` / `#e8e8e8` |

### 开发要点

- **缓存**：`_cached_results` 按 `(date, lat, lon, types, equipment)` 缓存，避免每次刷新都重算
- 向量化：用 `observer_pos.at(t_array)` 一次性计算所有时间步，比循环快几十倍
- 月相图标用 `pieslice` + 椭圆遮罩绘制（含 New / Full / Waxing / Waning 8 相位）
- 暗色主题（深蓝背景 + 浅灰文字），适合夜间观测不刺眼
- 默认地平线 profile 是作者后院，用户可自定义

## 6. Calendar

> 源码：[src/plugins/calendar/calendar.py](../src/plugins/calendar/calendar.py)

### 功能

从 **iCal URL**（Google Calendar / Apple / Outlook 等任何支持 ICS 订阅的服务）拉取事件，渲染为多种视图：

- `dayGridMonth` / `dayGrid` — 月历网格
- `listMonth` — 列表视图（按日期分组）
- `timeGridDay` — 单日时间轴
- `timeGridWeek` — 周时间轴（含"显示前几天"模式：固定周起始）
- `timeGrid` — 滚动周（从今天起 7 天）

支持多日历（每个 URL 独立颜色）、全天事件跨天展开、 recurring 事件展开（`recurring_ical_events` 库）。

### 依赖

- `recurring_ical_events` — 解析 recurring 事件
- `icalendar` — ICS 解析
- `pytz`
- 无 API Key

### 配置项

| 键 | 说明 |
|---|---|
| `calendarURLs[]` | ICS URL 数组（多日历） |
| `calendarColors[]` | 对应颜色数组（如 `#3788d8`） |
| `viewMode` | 视图模式（见上） |
| `displayTitle` | 显示标题 |
| `displayWeekends` | 显示周末 |
| `weekStartDay` | 周起始（0=周日, 1=周一） |
| `displayPreviousDays` | 周视图显示前几天 |
| `startTimeInterval` / `endTimeInterval` | 时间轴起止小时 |
| `fontSize` | `x-small` / `small` / `normal` / `large` / `x-large` |
| `backgroundColor` / `textColor` | 样式 |

### 开发要点

- `LOCALE_MAP` 提供多语言本地化（[constants.py](../src/plugins/calendar/constants.py)）
- 事件颜色由 URL 对应颜色决定，文字颜色自动计算对比色（`get_contrast_color`）
- 多日事件在月历中逐日展开
- 时间轴用 `px_per_min = hour_h / 60` 计算事件块位置
- `truncate_text` 自动截断过长事件标题
- `draw_rounded_rect` 绘制圆角事件块

## 9. Countdown

## 19. ShazamPi Music

> 源码：[src/plugins/shazam_pi/shazam_pi.py](../src/plugins/shazam_pi/shazam_pi.py)

### 功能

**音乐识别**插件，特性：

1. 通过 **USB 麦克风** 录音（44.1kHz → 降采样 16kHz）
2. 用 **YAMNet**（TFLite 模型）判断是否为音乐
3. 若是音乐，调用 **Shazam API** 识别歌曲
4. 显示专辑封面 + 歌曲名 + 艺术家
5. 无音乐时显示空闲界面（模糊时间 + 天气缓存）
6. 状态写入 `status.json` 供 Web UI 轮询

### 依赖

- `tflite-runtime`（或 `tensorflow`）
- `shazamio`（asyncio Shazam 客户端）
- `pyaudio`（录音）
- `numpy`
- **资源**：`ml-model/1.tflite`、`ml-model/yamnet_class_map.csv`、`resources/default.jpg`
- **硬件**：USB 麦克风
- 无 API Key

### 配置项

设置页极简（隐藏刷新间隔），主要靠自动运行。可配置：
- 录音时长
- 灵敏度阈值

### 开发要点

- **状态机**：录音 → YAMNet 检测 → Shazam 识别 → 显示结果 / 空闲界面
- **复用事件循环**：`self._event_loop` 避免每次创建 asyncio loop
- **连续 miss 计数**：`_consecutive_misses`，多次未识别到音乐则切空闲
- **天气缓存**：`WEATHER_CACHE_MINUTES=30`，空闲界面复用天气数据
- **e-ink 节流**：`EINK_IDLE_REFRESH_MINUTES=15`，e-ink 上空闲界面 15 分钟才重绘
- **ALSA 卡号缓存**：`_cached_mic_card` 避免每次重新探测
- **模糊时间**：`_fuzzy_time()` 返回 "It's about quarter past three" 等口语化时间
- **麦克风配置**：`_mic_configured` 标记 amixer 设置是否已应用
- **YAMNet**：Google 训练的音频事件分类模型，521 类，此处用于判断"是否为音乐"

### 最简插件模板

```python
from plugins.base_plugin.base_plugin import BasePlugin
from PIL import Image, ImageDraw
from utils.app_utils import get_font

class MyPlugin(BasePlugin):
    def generate_image(self, settings, device_config):
        width, height = device_config.get_resolution()
        if device_config.get_config("orientation") == "vertical":
            width, height = height, width

        img = Image.new("RGB", (width, height), "#ffffff")
        draw = ImageDraw.Draw(img)
        font = get_font("Jost", int(height * 0.05))
        draw.text((width // 2, height // 2), "Hello", font=font, fill="#000000", anchor="mm")
        return img
```
